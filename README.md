# همیار جنوب (نسخه مستقل گیت‌هاب و اندروید)

اپلیکیشن جامع روزمره برای **شهرستان مُهر، گله‌دار و اسیر، جم، لامرد و عسلویه** شامل:
- هواشناسی هوشمند و رنگی (با دمای حسی، نزدیک‌ترین روز بارندگی، نظر کارشناس بومی و راهنمای کشاورزی بومی مرتب‌شده بر اساس فصل)
- ساعات قطعی برق ۲۲ فیدر رسمی (پشتیبانی از جدول ۴ گروهی و ۵ گروهی)
- بانک اطلاعاتی ۱۱۸ منطقه (متصل به فایل `contacts-118.js`)
- دیوار محلی (ثبت آگهی رایگان با فشرده‌سازی خودکار تصویر)
- سفارش مستقل مصالح ساختمانی (بدون نام اشخاص، با محاسبه کرایه حمل و بارگیری و صدور فاکتور متنی و تصویری)
- پنل مدیریت مخفی (۵ بار لمس عنوان «همیار جنوب» یا `#admin` — رمز پیش‌فرض: `1234`)

## مراحل راه‌اندازی روی گیت‌هاب و اتصال آنلاین مستقل

1. **ساخت ریپازیتوری جدید:** در حساب گیت‌هاب یک ریپازیتوری جدید (مثلاً `hamyar-jonoob`) بسازید و تمام فایل‌های این پوشه را داخل آن آپلود کنید.
2. **جایگزینی فایل ۱۱۸:** فایل `contacts-118.js` خروجی گرفته‌شده از اسکریپت Colab را جایگزین فایل `contacts-118.js` فعلی کنید.
3. **فعال‌سازی GitHub Pages:** در تنظیمات ریپازیتوری به بخش `Settings > Pages` بروید و شاخه `main` را انتخاب کنید تا لینک HTTPS سایت فعال شود.
4. **اتصال به Firebase مستقل (برای آنلاین و زنده شدن همه اطلاعات):**
   - وارد `console.firebase.google.com` شوید و یک پروژه جدید (مثلاً `hamyar-jonoob`) بسازید.
   - از منو، بخش **Realtime Database** را بسازید.
   - آدرس دیتابیس (شبیه `https://hamyar-jonoob-default-rtdb.firebaseio.com`) را داخل فایل `firebase-config.js` در مقابل `DATABASE_URL` قرار دهید.
   - در تب `Rules` دیتابیس، قواعد زیر را تنظیم کنید تا خواندن برای همه آزاد باشد و نوشتن نیز برای بخش‌های مجاز فعال شود:
   ```json
   {
     "rules": {
       "hamyar_jonoob": {
         ".read": true,
         ".write": true
       }
     }
   }
   ```
5. **دریافت فایل نصبی اندروید (`.apk`):** پس از هر بار تغییر در ریپازیتوری، به تب **Actions** در گیت‌هاب بروید و فایل `hamyar-jonoob-apk` را دانلود کنید.
